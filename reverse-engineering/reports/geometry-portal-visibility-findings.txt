Observed native contracts
0x600bd0 assigns global0x280a2f0 to GSNH+0x13c. Modern clear/set helpers write
exactly625 bytes (5000 bits), independent of scene instance count. Buffer
canaries remain intact. The legacy branch changes only bit4 in flags+0x44 of
80-byte instances, retaining every other flag. Root-room0x600be0 marks all
members unconditionally. IDs and counts must be valid signed16 values.

Clipped-room0x600d00 first skips an already visible bit, then accepts an override
bit at display+0x88 before checking flags. With display+0x74 bit0x4000 set,
instance flag1 is required; flag8 bypasses geometry; otherwise center/extent
bounds must pass0x5d9770. In alternate mode, flag1 is not required; flag8 still
bypasses geometry; sphere result1 accepts, result2 refines with min/max bounds.
Both branches consume display+0x48 flag bytes. The helper's apparent null-display
condition is not safe null support: later loads dereference that same pointer.
The portable clipped-room helper therefore covers nonnull display scenes only.

Sphere classification tests prepared planes plus the extra global camera plane.
It rejects distance < -radius; full acceptance requires distance > radius for
every plane; tangency gives partial2. Center/extent classification does not test
that extra camera plane, rejects strictly below negative support radius, and
accepts tangency. Min/max uses eight corners with distance >=0 inside, returning
0 for all-eight-outside any plane,1 for all-inside, otherwise2. Exact software
x87 intermediates plus the observed float32 stores preserve tiny authored
coefficients. All finite inputs are bounded; malformed indices/negative extents
are rejected by portable adapters rather than reproducing unsafe native reads.

Portable source

It compiles with the other geometry modules and shared AnimationPlayback.cs /

Boundary still open
These consumers close the previously supplied per-room visibility bit writes.
They do not reconstruct recursive0x5ee940 control, allocator/child volumes,
screen projection/intersection, portal activation, grid/tree visibility,
camera production or GPU pixels. Clip planes in these tests are explicit
prepared fixtures, never labelled as recovered child volumes.
