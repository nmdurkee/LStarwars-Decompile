state
CharacterSubmissionState is authoritative for shared806ccc visibility,9715a0 submission mask and allocator cursor. The bridge mirrors these before each dynamic call, reads the changed cursor/mask afterward, and restores both typed projections after the outer character routine returns. Original mode0/2 is preserved by the character loop, but the normal dynamic branch does not consume that third native argument.

palette
The layer loop reserves each smooth palette before rigid draws. The bridge writes palette matrices only at the later smooth call, reads the exact forwarded pointer for mesh-local matrix selection, and materializes palettes even when every smooth handle is invalid. Existing palettes in a reused state are not rewritten. Matrix scratch is explicit, valid and disjoint; it represents the original transient stack matrix.

packets
Each actual dynamic call performs recovered visibility/LOD/material selection, shader emission, allocator links, ordinary/prefix or skin/morph packet output. Only nonnull skin resolves a typed source mesh. Weights are read at native weight-pointer+8 and count at mesh+40; rigid draws do not resolve a mesh or dereference weights. The adapter verifies resolved resource identity and forwards original metadata/alpha.
