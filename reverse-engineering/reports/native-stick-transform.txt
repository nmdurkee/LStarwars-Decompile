Status: assembly reconstruction corroborated by isolated emulation of original machine code and original callees, not by running the game.

The input polling function 0x006d74e0 calls this on each signed-int16 stick pair after Y inversion. The operation stretches radial input toward square corners, with a small 32767/32768 scale factor and signed saturation. It is not the later gameplay deadzone filter.

Let f32 round to IEEE float32, trunc round toward zero, x/y be signed int16 input:
  maximum = max(abs(x), abs(y))
  magnitude = f32(sqrt(f32(x*x + y*y)))
  ratio = maximum != 0 ? f32(32767 / maximum) : 1
  scale = f32(f32(ratio * magnitude) / 32768)
  output_x = trunc(clamp(f32(x * scale), -32767, 32767))
  output_y = trunc(clamp(f32(y * scale), -32767, 32767))
