Layout anchors for future work
NU20 begins at u32(file+0)+4. PNTR and GSNH are relative pointers at NU20+0x18 and +0x1c. Relative pointer targets are field address plus signed i32. Saved unused runtime pointer values can be invalid and must not be followed blindly.
Current mesh packets are 56 bytes: primitive type +0, strip index/triangle count +4, stride u16 +8, eight-byte joint palette +0x0a, base vertex +0x14, vertex count +0x18, first index +0x1c, IB +0x20, VB +0x24, shape count +0x28, shape offsets relptr +0x2c, dynamic vertices +0x34. Two legacy vehicle GSCs use 100-byte mesh and 628-byte material records. Their vertex stride/index offsets differ and are handled explicitly.
Display items are 16 bytes: type +0, flags +1, field-relative resource pointer +4. Recovered types: 0x80 material, 0x82 mesh, 0x83 matrix, 0x8e end, 0x8f billboard. Material association is scoped through static lists and model records; it is not inferred by carrying one material globally across unrelated lists.
Special objects are 208 bytes: initial matrix +0, draw matrix +64, bounds center +128, extent +144, model relptr +0xb0, name relptr +0xb4, flags +0xb8, bounds index +0xc0, IABL relptr +0xc4. Named nodes carry sourceAddress/sourceModel/boundsIndex in extras for joins. Scene animation replaces the linear transform and adds original draw-matrix translation; see animation agent evidence.
17 source affine matrices required two-node TRS factorization for glTF. NumPy SVD A=U diag(s) Vt retains proper rotations, signed scale and original matrix in extras. Max absolute reconstruction error 1.913e-11; relative 4.687e-15. geometry-affine-factorization.json maps original parent and residual basis child. No source positions were discarded. An animated consumer replacing the full native matrix must neutralize that residual basis rotation in its separate animated output.
Billboard packets contain 6 vertices per face, 32 bytes per vertex: center float3, BGRA color, UV float2, corner float2. glTF previews expand into fixed XY planes. Original dedicated face-on shader 0x769e98, material selector 0x608000 and transform callback 0x5fda20 now have documented camera-facing center/corner transform, U flip, doubled alpha, tint and fog formulas. Twelve original-code cases / 60 constant uploads pass; see geometry-billboard-shaders.json. This dedicated path is separate from the generic HLSL template.
PORT room stride is 24 bytes for these PC files (not 20). Bounds, plane/point/object references and portal links are validated. Spline NTBL packed offsets are resolved and all 5,249 names are present. Dynamic INID indices and source bounding-box IDs support the gameplay agent's TER platform attachment joins.
