SCENERY ANIMATION POSE

103156 exact original-PC vector/matrix comparisons, 0 mismatches; 16127 authored clips.

payload
SceneAnimationClip clones the single-node nine-channel ANI4 or ANI5 payload; ANI4 offsets are payload-relative and ANI5 signed pointers field-relative. Native loaded absolute pointers are not accepted. Range-checked source padding must include all packed endpoint reads even if the final interpolation fraction is zero.

keyTime
0x5ce350 stores frame-first tofloat32, stores its product with(keyCount-1), stores division by(frameCount-1), then clamps to0..keyCount-1. A one-key clip chooses key0. Whole key truncates, low2bits select one of4 packed subkeys, and a per-channel mask lowbit suppresses fractional interpolation.

packed6
Factors use the original qword0.015873020514845848 and separatefloat32 stores. Subkeys0..2 also store the interpolated factor before applying endpoint range. Subkey3 stores both endpoint reconstructions before interpolation. Per-channel scale and minimum use one finalfloat32store.

packed16
For subkeys0..2, the interpolated12-bit weight divided by4095 is storedfloat32 before endpoint range/scale/minimum. Subkey3 stores reconstructed values from both neighboring packed blocks before interpolation. Constants use u16table*globalScale+globalMinimum with one store.

matrix
Scene rotation channels3..5 are Euler radians, scaled by original qword10430.3779296875 and truncated towardzero toint32.0x5b5300 uses the original32768-value sine table and x87 operation order. Flagsbit1 enables rotation;bit8 enables row scale;translation channels0..2 always apply. Final sign flips are matrixindices2,6,8,9,11,14.

cache
552760 returns for missing resolvedtarget, missingclip, or equal previous evaluation. Otherwise evaluate target, update previous time, copy to unoffset cache, add base translation to target, then invoke bounds update. ApplyWork consumes scene-tick decisions: evaluate cache only when requested, but copy cache to target whenever CopyPose istrue, adding base translation after each copy.

integration
A SceneAnimationPoseBinding connects the existing ScenePlaybackInstance to its source clip, matrix cache, target transform and base translation. UpdateScene output must be applied in source order before UpdateGroups; group changed-frame hooks call EvaluateChangedFrame. Full native pointer resolution and renderer-owned5ea660/5df480 bounds effects remain a host boundary.
