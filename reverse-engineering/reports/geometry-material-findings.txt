ORIGINAL PC MATERIAL AND SHADER CONTRACTS

Scope
This report supplements geometry-findings.txt. The source binary SHA-256 is 6c9c2b35aa9452ba36c4f816a4ae50e3e8de133971ae1899a20de102d7e20adb. Original Windows game code was not launched. Bounded original functions ran inside Unicorn with GPU/upload boundaries intercepted. Native arithmetic, feature predicates and packed-color conversion executed unchanged. These contracts improve rendering reconstruction evidence; they do not establish final GPU pixel equivalence.

Original classes and shader source
Original RTTI identifies HLSLShaderBuilder at vtable 0x7e9320 and ShaderManagerHLSL at 0x7e93a4. Constructor 0x746020 belongs to ShaderManagerHLSL and constructs HLSLShaderBuilder internally. Call 0x7460ac passes the exact embedded template at VA 0x82d6f0, length 0x26b6f (158,575 bytes), into 0x749390 -> 0x748bf0. The extracted template is exports/shaders/nu2-embedded-template.hlsl, SHA-256 c8669119db9bb154e5ed26b764175443b57bbd965cab9a71d4d47ae2eba3b1ab. Original shader compiler caller 0x743da0 requests vertexProgram/fragmentProgram entry points. Profiles 1,2,3,4 select vs_1_1/ps_1_1, vs_2_0/ps_2_0, vs_2_a/ps_2_a, and vs_3_0/ps_3_0. Compiler flags 0x200 gain 0x10000 for profile < 2. See native-shader-source.json, native-shaders.json and native-rtti.json.

Material feature emission
geometry-material-native-programs.json covers all 49,109 current 708-byte records from all 1,477 carriers. Original feature builder 0x749570 was invoked for 21,367 distinct authored descriptor/DDS-format combinations across four profiles and color/shadow contexts: 170,936 native calls, 3,792 distinct ordered emission variants, zero errors. Emission boundary 0x747320 records name, value and kind. Redefinitions are retained and the last definition wins. Per-material variant hashes under exports/geometry/material-programs resolve against the global report.
Context is explicit: authored descriptor at material+0xb4, absent ID threshold -1, vendor 0, directional lightmap false, one render target, no auxiliary normal/motion/depth output. Normal-map resource queries supply the actual embedded DDS format. The report does not claim the full range of live GPU/vendor/render-target permutations or material post-load mutations. The 46 legacy 628-byte records remain preserved with viewable geometry but are excluded from current-layout native shader calls. Bounded original-code tracing now confirms the ordinary loader retains their 628-byte stride and reaches current-layout fixup without expansion; see geometry-legacy-loader-native.json. Original descriptor bytes and emission order are more authoritative than the older cross-version feature labels.

Uniform and texture bindings

It maps 29 material uniform formulas and 15 texture sampler bindings to their exact original names and byte offsets. All 68 emitted macro names are cross-referenced against template line numbers. 67 occur; SPECULAR_STAGE has no occurrence in this particular template, which is retained as a fact rather than assigned invented meaning.
Original binder 0x742730 and color converter 0x742120 independently validate all 29 formulas for all 49,109 current records: 1,424,161 uniform checks, 4,567,137 scalar comparisons, 46,200 unique native calls, zero errors, maximum normalized error 1.135326489812318e-7. Specular-power global 0x82b020 uses its default 1. There are 98,210 classified nonfinite comparisons from inactive candidate formulas such as zero divided by zero. Their explicit NaN/Infinity markers do not mean the original renderer requests or uploads those unused uniforms. The native check intercepts upload boundaries only; arithmetic and RGBA conversion run unchanged. See geometry-material-uniform-native.json.

Dedicated face-on billboards
The billboard path is separate precompiled shaders, not a branch in the generic Nu2 HLSL template. Initializer 0x60ddc0 pairs vertex shader 0x769e98 with pixel shaders 0x76a2b0 (ps_1_1) and 0x76a3e0 (ps_2_0). Material callback 0x608000 first handles debris bit 0x100000, then face-on bit 0x200000 at material+0x1f0. The high face-on program is selected when global 0x2976c80 is nonzero and the low nibble of material+0x268 is nonzero; otherwise the low program is used. Diffuse texture is material+0xb8, unit 0. Full retained assembly and exact formulas are in geometry-native-material-callback.asm and geometry-billboard-shaders.json.
Each 32-byte vertex supplies center float3, BGRA color, UV float2 and corner float2. The original vertex program transforms the center by faceOnMtx and adds faceOnTranslation. It scales the corner by faceOnMag.x and rotates/translates it through viewMtx, combines it with the center, then projects using viewProj. It outputs UV (-u,v), doubles vertex alpha before tint, and computes exponential squared-distance fog. Both pixel shaders multiply diffuse texture and vertex color and blend RGB with fog. The high shader additionally writes [0.5,0.5,0.5,1] to a second render target.
Original callback 0x5fda20 consumes a 132-byte transform packet: matrix at +0, magnitude at +64, view matrix at +68. It extracts original matrix translation, clears that translation, replaces m33 with 1, transposes both matrices for upload, and multiplies tint alpha by saved m33 only if below 1. Twelve deterministic original-code cases validate 60 matrix, translation, magnitude and tint uploads with zero differences. Native tint upload passes count 4; only the first four floats consumed by reflected kTint are compared. The live packet producer and native GPU rasterization are not reconstructed. glTF remains the explicitly labelled fixed XY approximation, preserving original center/corner data.

RAW companions
The PC gradient initialization chain 0x48a6a0 -> 0x5f8d60 and particle chain 0x48a6a0 -> 0x683530 -> 0x682b10 -> 0x546fd0 -> 0x5f8d60 use the DDS extension and PC platform literals. Original filename functions 0x4f90c0 -> 0x4f8f10, emulated with five inputs, produce stuff\gradient_PC.dds and stuff\particle_PC.dds even when passed .raw names. Thus these PC initialization paths do not consume the loose RAW companions. This does not prove they are unreachable through every possible path, and does not establish their channel order. Both labelled candidate previews and original bytes remain. See geometry-raw-loader-evidence.json.

Remaining limits
Generic glTF PBR is approximate. Native feature emissions, material uniforms and dedicated billboard math are recovered contracts, not a completed renderer. Uncovered live variants, legacy material preprocessing, all shader-consumed vertex channels, live UV scheduling, lighting/shadow/environment state, draw ordering and actual GPU pixel comparison remain explicit. No Unity or Quest implementation was added.
