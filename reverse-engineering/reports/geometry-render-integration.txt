Frame timing and production

Platform completion0x4fd050 calls UV wrapper0x601330, ATS scheduler0x5d34a0 and

Scene animation0x5f4b90 belongs to update and is not itself draw submission.

Playback and callback dispatch
0x60aff0 loops536-byte contexts, establishes clear/pass/target state, and calls
0x5f02e0 for each nonnegative bucket ID. That plays sorted scene-list pointers
in their prepared order, then the inline tail. 0x6033d0 invokes0x5e0f90 with
the current table pointer at0x80e794. Selection0x603aa0 chooses49-entry table
0x80e6d0 (selector0) or0x80e798 (selector1); pass names remain unassigned.

The native interpreter uses16-byte items. Byte+1 is control:0 skips/advances,
1 jumps to pointer+4,3 dispatches and advances,4 returns. Byte+0 is the opcode;
for control3 it selects callback[(opcode-0x80)], ignores a null callback, and
passes item+4 as the sole argument. Native producers use0x84/control4 and
0x8d/control1. Serialized opcode labels alone do not define termination.
Invalid control values loop in native code; bounded tools must reject them.

Primary callbacks include0x80->608000 material,0x82/8b/98->607880 mesh,
0x83->5fd6b0 matrix,0x8f->5fd9f0 billboard mesh,0x90->5fda20 billboard transform.
The secondary table changes material to6083d0 and matrix to5fd940 and suppresses
several other callbacks. All49 entries of both exact tables are preserved.

Material608000 looks up signed16 shader index at material+0x1f4 using741620,
sets current material0x2854c20, invokes uniform binder742730 and shader setter

The secondary callback uses shader index+0x1f6. Dedicated debris/face-on branches
are selected from flags+0x1f0, consistent with earlier shader findings. This
connects prior material feature/uniform tests to the actual playback callback.
